# Bryan Samuel James — Portfolio (React + Tailwind)

This is a fast, modern portfolio built with **Vite + React (TypeScript)**, **Tailwind**, and **Framer Motion**.

## Quick start

1) Install Node.js 18+  
2) In this folder:

```bash
npm install
npm run dev
```

## Customize

- Edit content in: `src/data/profile.ts`
- Put your resume at: `public/Bryan_Samuel_James_Resume.pdf`
- Replace OpenGraph image: `public/og.png` (1200×630 recommended)

## Deploy

- **Vercel**: import repo → deploy
- **Netlify**: build `npm run build`, publish `dist`
- **GitHub Pages**: use a Pages workflow (or deploy via Netlify)

## Standout features

- Ctrl+K command palette
- Dark/light theme with no-flash load
- Filterable projects + searchable skills
- Clean, recruiter-first layout (scan in < 60 seconds)
